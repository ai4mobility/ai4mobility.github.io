Most likely first tokens
<tool_call>

I
→ it will write a tool call, not an answer
P(k) = eVk / Σj eVj
The multinomial logit you use for mode or route choice. k: one alternative (here, a next token). Vk: its utility, computed from everything in the prompt. Change the prompt and you change the utilities.
The model writes one token at a time. Before the first one, it gives every possible next token a probability. If <tool_call> wins, it is about to call a tool.

C · the engineer's description
Active work on one street near a place, counted as works rather than records. feed: 'FL', 'AZ' or a name from list_feeds. street: a street name as people say it ('Busch Blvd', 'N 30th St', 'Fowler Avenue'); suffixes and directions may be spelled out or abbreviated, and a name without N/S/E/W matches every direction prefix. near_lat, near_lon and radius_mi (default 5 mi) give the place, because street names repeat across a state (Florida's feed has a 109th Avenue in Tampa and another 200 mi away). One work (a permit or a project) is often reported as several records, one per segment and direction: the result lists each work with its records' directions, lane impact, closed lanes, end time in local time and reporting organization. 'Lane impact not reported' means the feed does not say; it does not mean the lanes are open. The result also says how many active records near the place have no street name, which a search by name cannot find. For route numbers (I-75, SR 580, US 41) use get_work_zones. Read-only.

Before you trust this




What is the baseline? Setup B: the same code as C, with a programmer's description and a
raw result. Same model, same question, same seed. On the closed-model page, Claude also runs with raw data and code (R) and with
the toolkit alone (A).


How was the data split, and why is that honest? Nothing is trained here, so there is no
split. The checked answer and the three traps were written before any run, and the probes read a copy of the conversation:
they never enter the run.


The ugly cases. One question, one small model, one seed. In B the pick was nearly a
three-way tie (39%, 32%, 29%), so another seed could have drawn the new tool.
The bars are probabilities at temperature 1; the run sampled at 0.7. The belief probe asks the model a question it was not
asked in the run.
