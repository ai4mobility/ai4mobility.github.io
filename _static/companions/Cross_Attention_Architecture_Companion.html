How to read the animation

Source: “Crash blocks right lane ahead.” Scripted output: “Right lane closed.” We use whole words as simplified tokens; a real tokenizer may split them differently. Each encoder vector contains contextual information, not just the meaning of its displayed word.

Select “‹start›” to inspect the query used to predict Right; select “Right” to inspect the query used to predict lane. A decoder input token and its next-token target are offset by one position. The future positions shown in the selector are for inspection: they are masked from the selected position's self-attention.

Green paths show query-to-key matching. Gold paths show values traveling back into a weighted context vector; thicker paths carry larger weights. Cross-attention updates decoder representations. It does not update the stored encoder memory during this forward pass.

The calculation behind one attention head

qᵢ = hᵢ WQ; kⱼ = zⱼ WK; vⱼ = zⱼ WV. Here hᵢ is the decoder state after masked self-attention; zⱼ is the encoder state for source position j. The W matrices are learned projections. This demo starts with hand-chosen projected vectors.

sᵢⱼ = (qᵢ · kⱼ) / √dₖ, aᵢⱼ = exp(sᵢⱼ) / Σₘ exp(sᵢₘ), cᵢ = Σⱼ aᵢⱼ vⱼ.

The score measures query–key compatibility. Softmax normalizes over source positions; each row sums to one before rounding. The context c is a weighted sum of value vectors, not words, keys, or vocabulary probabilities. Our vectors have two abstract, unitless coordinates, so dₖ = 2.

PhD lens: If all four positions are evaluated together during teacher-forced training, Q is 4 × 2, K and V are 5 × 2, the attention matrix is 4 × 5, and the head output is 4 × 2. Each row uses a causally masked decoder prefix. During generation, only the new query needs to be evaluated when caches are used. Multiple heads use their own projections; their outputs are concatenated and projected before the rest of the decoder.

Connect this back to the encoder–decoder figure

The Z of the encoder–decoder figure (Bishop & Bishop, Fig. 12.20, drawn token by token in section 2.9) is [z₁, z₂, …, z₅] here: one final encoder vector per input token. The horizontal arrows carry that sequence to the cross-attention sublayer in each decoder layer. Each decoder layer has its own projection matrices even though it reads the same Z.

The walkthrough expands the decoder block into masked self-attention, cross-attention, and a feed-forward network. Residual connections and normalization surround these sublayers; their wiring is abbreviated to keep the token paths readable. Positional information is added on both input sides.

The top output head maps the final decoder state to vocabulary scores and softmax probabilities. Its predicted token is fed back as the next decoder input, until an end token is selected. The output words in this walkthrough are scripted to explain that loop; they are not predictions computed from a trained decoder.

Try it, then carry it further

Three minutes: Before you press anything, count how many vectors Z contains. Select “‹start›,” step through matching and mixing, then select “Right” and “lane” and compare their attention over the same encoder memory. Why are the future decoder tokens masked while every source token stays visible?

Bridge to the crash-diagram test: Replace the five encoder word tokens with image-patch vectors. Narrative states can still supply Q while diagram-patch states supply K and V. Cross-attention does not itself require autoregressive generation: the BLIP matching test in section 2.9 uses a bidirectional text stream and a matching head, so its decoder masking and next-token output differ from this generative example.

Transportation task: Draft one incident message from an available roadway report, for operator review before display. Compare with a template based on verified lane-closure fields. Evaluate factual correctness of lane, direction, location, and closure status—not just fluent wording. A large weight is not proof of a causal explanation; a model can attend to “lane” and still miss a negation such as “lane is not closed.”
