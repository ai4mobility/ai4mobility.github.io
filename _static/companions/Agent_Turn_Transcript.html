Inside the signal agent’s turns: what the model was sent, what it called, and why

Every request of one AI agent run through a simulated hurricane in Tampa, recorded as it happened: the system prompt, the tool list, the history so far, the summary of the model’s thinking, each tool call and each result. Nothing is rewritten.

How a turn works

An agent is a model in a loop. A program on the TMC side, the harness, sends the model everything it needs in one request. The model answers with tool calls. The harness runs the tools, adds their results to the conversation, and sends the whole thing again. The turn ends when the plan is sent and the status memo is written.

The model never touches the simulator, the optimizer or the people. It only writes tool calls; the harness decides what each call is allowed to do. Numbers on the figure are from this run.
